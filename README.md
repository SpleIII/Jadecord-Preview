## 🧩 О проекте

**Jadecord** — учебный командный проект: интерфейс мессенджера, собранный с нуля и максимально
близкий к оригинальному Discord. Размеры сетки и палитра взяты не «на глаз», а из публичных
стилей `discord.com/app`:

| Параметр | Значение |
|---|---|
| Рельс серверов | `72px` |
| Сайдбар каналов | `280px` |
| Шапка канала | `49px` |
| Список участников | `240px` |
| Аватар сервера | `40px` |
| Фирменный цвет | `#5865F2` |
| Статус «в сети» | `#3D9E60` |

Темы оформления повторяют три темы Discord — `theme-dark`, `theme-darker` и `theme-light` —
с настоящими значениями палитры `neutral-*`.

## ✨ Возможности

| Раздел | Что реализовано |
|---|---|
| **Экран загрузки** | анимированный логотип, полоса прогресса и вращающиеся подсказки |
| **Рельс серверов** | иконки серверов, индикатор активного, разделитель и кнопка добавления |
| **Каналы** | текстовые и голосовые, участники в голосовых, поиск и переключение |
| **Чат** | группировка сообщений, `**жирный**`, `` `код` ``, ссылки, реакции, карточки проектов |
| **Участники** | список онлайн/оффлайн, статусы, бейджи ролей, карточка профиля по наведению и клику |
| **Rich Presence** | активности, смена статуса и «играет» в один клик |
| **Темы** | переключение тёмной, самой тёмной и светлой темы |
| **Хранение** | сообщения, тема, статус и активность сохраняются в `localStorage` |

Интерфейс адаптируется под ширину окна: на узких экранах список участников и сайдбар
убираются, чтобы не мешать переписке.

## 🛠️ Технологии

| Слой | Что используется |
|---|---|
| Разметка | HTML5, семантические теги, ARIA-атрибуты |
| Стили | CSS3: кастомные свойства, flex/grid, анимации, три темы |
| Логика | Vanilla JS (ES2020+), IIFE, без фреймворков и сборщиков |
| Данные | `js/data.js` — единственный файл, который нужно править под свой контент |
| Хранение | `localStorage` |
| Публикация | GitHub Pages (статика) |

## 🚀 Запуск

Клонируйте репозиторий и откройте страницу клиента:

```bash
git clone https://github.com/SpleIII/Jadecord-Preview.git
cd Jadecord-Preview
```

Файл `pages/app/index.html` работает и при простом открытии в браузере, но для стабильного
`localStorage` лучше поднять локальный сервер:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000/pages/app/
```

## 📄 Лицензия

Учебный проект. **Discord** — товарный знак Discord Inc.; этот репозиторий не связан с компанией
и не использует её исходный код. Разметка, стили и логика написаны с нуля, а числовые значения
дизайна взяты из публичных стилей приложения как справочные.
